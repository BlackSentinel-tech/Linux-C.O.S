Live sessionSesión live

Booting the ISO takes you straight to the XFCE desktop as user kali (password kali, needed for sudo and the installer). Nothing persists: everything is lost at shutdown.Al arrancar la ISO entras directamente al escritorio XFCE como el usuario kali (contraseña kali, necesaria para sudo y el instalador). Nada persiste: todo se pierde al apagar.

  • The firewall is already on (deny incoming).El firewall ya está activo (deniega lo entrante).
  • The live session never downloads the BlackArch image on its own — it would fill your RAM. Run blackarch-shell --update if you want it anyway.La sesión live nunca descarga la imagen de BlackArch por su cuenta — llenaría tu RAM. Ejecuta blackarch-shell --update si igual la quieres.

Offensive toolsHerramientas ofensivas

Kali's and Parrot's tools are regular packages: start them from the menu categories or by name in a terminal. To list what's installed:Las herramientas de Kali y Parrot son paquetes normales: ábrelas desde las categorías del menú o por su nombre en una terminal. Para ver lo instalado:

apt list --installed 'kali-tools-*'

Looking for a specific tool? Use the tool catalog.¿Buscas una herramienta concreta? Usa el catálogo de herramientas.

blackarch-shell

BlackArch is Arch Linux; its packages can't be installed with apt. blackarch-shell runs it unmodified in Docker, with your home directory mounted at the same path inside.BlackArch es Arch Linux; sus paquetes no se instalan con apt. blackarch-shell lo ejecuta sin modificar en Docker, con tu carpeta personal montada en la misma ruta.

blackarch-shell              # open (or re-join) the shell# abrir (o volver a) la shell
blackarch-shell nmap -h      # run one command# ejecutar un solo comando
blackarch-shell --status     # image present? container running?# ¿hay imagen? ¿contenedor en marcha?
blackarch-shell --update     # download BlackArch's official image# descargar la imagen oficial de BlackArch

Inside the container: pacman -Ss <name> searches, pacman -S <name> installs.Dentro del contenedor: pacman -Ss <nombre> busca, pacman -S <nombre> instala.

cos-stacks

Starts and stops the heavy blue-team platforms. Run it without arguments for an interactive menu.Inicia y detiene las plataformas blue-team pesadas. Ejecútalo sin argumentos para ver un menú interactivo.

cos-stacks                   # interactive menu# menú interactivo
cos-stacks list              # every stack and its status# todos los stacks y su estado
cos-stacks info misp         # URL, RAM needed, notes# URL, RAM necesaria, notas
cos-stacks up misp           # start (MISP: generates random passwords)# iniciar (MISP: genera contraseñas aleatorias)
cos-stacks creds misp        # how to log in# cómo iniciar sesión
cos-stacks logs misp         # follow logs (Ctrl+C to stop)# seguir los logs (Ctrl+C para parar)
cos-stacks down misp         # stop (data is kept)# detener (los datos se conservan)

Why only localhost?¿Por qué solo localhost?

Ports published by Docker bypass ufw. Every web UI and API (Wazuh's dashboard, indexer and API included) is bound to 127.0.0.1 until you decide otherwise. The only network-facing ports are Wazuh's agent ports 1514/1515, so agents can enroll.Los puertos publicados por Docker se saltan ufw. Todas las interfaces web y APIs (incluidos el panel, el indexador y la API de Wazuh) escuchan en 127.0.0.1 hasta que decidas lo contrario. Los únicos puertos abiertos a la red son los de agentes de Wazuh, 1514/1515, para que los agentes puedan registrarse.

PasswordsContraseñas

MISP's passwords are generated at random on its first start. TheHive and Wazuh start with their upstream first-login defaults — cos-stacks creds <stack> shows them; change them on first login.Las contraseñas de MISP se generan al azar en su primer arranque. TheHive y Wazuh empiezan con los valores de fábrica de sus proyectos — cos-stacks creds <stack> los muestra; cámbialos en el primer inicio de sesión.

Installing to diskInstalar en disco

  1. Double-click Install Linux-C.O.S on the desktop and enter the password kali.Haz doble clic en Instalar Linux-C.O.S en el escritorio e introduce la contraseña kali.
  2. Pick language, location and keyboard.Elige idioma, ubicación y teclado.
  3. Partitions: “Erase disk” (the default) deletes everything on that disk, Windows included. To keep another system, back up and choose “Install alongside” or manual partitioning. Tick Encrypt system for LUKS2 full-disk encryption (recommended). ext4, btrfs and xfs are offered; you need 60 GB.Particiones: “Borrar disco” (lo predeterminado) elimina todo lo que hay en ese disco, Windows incluido. Para conservar otro sistema, haz una copia de seguridad y elige “Instalar junto a” o el particionado manual. Marca Cifrar el sistema para el cifrado completo LUKS2 (recomendado). Se ofrecen ext4, btrfs y xfs; necesitas 60 GB.
  4. Create your user (password of 8+ characters) and, on the next screen, a separate root password. Your user joins the sudo, docker and wireshark groups — note that the docker group is root-equivalent.Crea tu usuario (contraseña de 8+ caracteres) y, en la pantalla siguiente, una contraseña de root aparte. Tu usuario entra en los grupos sudo, docker y wireshark — ten en cuenta que el grupo docker equivale a root.
  5. Review the summary and install. Live-only packages and the live autologin are removed from the installed system.Revisa el resumen e instala. Los paquetes de la sesión live y su autologin se eliminan del sistema instalado.

First bootPrimer arranque

On the first boot of the installed system, linux-cos-firstboot enables the firewall permanently — before the network comes up — and linux-cos-blackarch-pull then loads the BlackArch image (from the ISO if it was baked in, otherwise it downloads it once in the background).En el primer arranque del sistema instalado, linux-cos-firstboot activa el firewall de forma permanente — antes de que arranque la red — y después linux-cos-blackarch-pull carga la imagen de BlackArch (desde la ISO si se incluyó, si no la descarga una vez en segundo plano).

Defensive tools that need one step from youHerramientas defensivas que necesitan un paso tuyo

  • wazuh-agent is installed but not enrolled: set your manager's address in /var/ossec/etc/ossec.conf, then sudo systemctl enable --now wazuh-agent.wazuh-agent está instalado pero no registrado: pon la dirección de tu manager en /var/ossec/etc/ossec.conf y luego sudo systemctl enable --now wazuh-agent.
  • AIDE needs a baseline of a system you trust: sudo aideinit once (it takes a while), then sudo aide --check.AIDE necesita una referencia de un sistema en el que confíes: sudo aideinit una vez (tarda un rato) y luego sudo aide --check.
  • Suricata is off: sudo systemctl enable --now suricata when this box should watch a network.Suricata está apagado: sudo systemctl enable --now suricata cuando este equipo deba vigilar una red.
journalctl -u linux-cos-firstboot -u linux-cos-blackarch-pull

TroubleshootingSolución de problemas

“the Docker daemon is not running”“the Docker daemon is not running”

sudo systemctl start docker

“permission denied” on the Docker socket“permission denied” en el socket de Docker

Group changes only apply to new logins. Log out and back in; until then the Linux-C.O.S commands fall back to sudo automatically.Los cambios de grupo solo se aplican en nuevos inicios de sesión. Cierra sesión y vuelve a entrar; mientras tanto los comandos de Linux-C.O.S usan sudo automáticamente.

It doesn't boot on real hardwareNo arranca en hardware real

Disable Secure Boot in the firmware settings — this release has no signed bootloader yet.Desactiva Secure Boot en la configuración del firmware — esta versión todavía no tiene un cargador de arranque firmado.

Boot is extremely slow in UTM on a MacEl arranque es muy lento en UTM en un Mac

Expected on Apple Silicon: an x86_64 guest is emulated in software. Several minutes from GRUB to the desktop is normal.Es normal en Apple Silicon: un invitado x86_64 se emula por software. Varios minutos desde GRUB hasta el escritorio es lo esperado.
