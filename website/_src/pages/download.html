Build the ISOCompilar la ISO

  1. Get the sourceDescarga el código

    git clone {{REPO}}.git
cd Linux-C.O.S/build

  2. Decide on BlackArch (optional)Decide sobre BlackArch (opcional)

    By default the BlackArch image is downloaded on the first boot of an installed system. To bake it into the ISO instead (much bigger ISO, zero download after boot):Por defecto la imagen de BlackArch se descarga en el primer arranque del sistema instalado. Para incluirla en la ISO (ISO mucho más grande, cero descargas después):

    docker build -t linux-cos/blackarch:latest blackarch-container/
docker save linux-cos/blackarch:latest -o config/includes.chroot/opt/linux-cos/blackarch-image.tar

  3. Build (in the background)Compila (en segundo plano)

    nohup ./build.sh > build.out 2>&1 &
tail -f output/build.log

    The ISO lands in build/output/live-image-amd64.hybrid.iso.La ISO queda en build/output/live-image-amd64.hybrid.iso.

  4. Verify a downloaded ISOVerifica una ISO descargada

    Compare the output with the SHA256SUMS file published next to the release:Compara el resultado con el archivo SHA256SUMS publicado junto a la versión:

    sha256sum -c SHA256SUMS --ignore-missing

Boot itArráncala

USB stickMemoria USB

Write the ISO with balenaEtcher, Rufus (DD mode) or dd. Double-check the device name — dd overwrites whatever you point it at.Graba la ISO con balenaEtcher, Rufus (modo DD) o dd. Revisa bien el nombre del dispositivo — dd sobrescribe lo que le indiques.

# Linux: find the stick with lsblk first
sudo dd if=live-image-amd64.hybrid.iso of=/dev/sdX bs=4M status=progress conv=fsync
