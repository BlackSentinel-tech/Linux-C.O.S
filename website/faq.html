What is Linux-C.O.S, exactly?¿Qué es exactamente Linux-C.O.S?

A security-focused Linux distribution with its own name, branding, defaults and installer, built on Kali's rolling repository — the same way Kali and Parrot are built on Debian. It combines offensive tooling (Kali, Parrot, BlackArch) with a blue-team stack and a hardened base.Una distribución Linux enfocada en seguridad, con nombre, marca, valores por defecto e instalador propios, construida sobre el repositorio rolling de Kali — igual que Kali y Parrot se construyen sobre Debian. Combina herramientas ofensivas (Kali, Parrot, BlackArch) con un stack blue-team y una base endurecida.

Is it affiliated with Kali, Parrot or BlackArch?¿Está afiliada a Kali, Parrot o BlackArch?

No. It uses their public repositories and images, and credits them, but it is an independent project.No. Usa sus repositorios e imágenes públicos y les da crédito, pero es un proyecto independiente.

Why is BlackArch in a container instead of installed?¿Por qué BlackArch va en un contenedor y no instalado?

BlackArch is Arch Linux (pacman packages); Linux-C.O.S is Debian-family (apt). The formats don't interoperate, and repackaging 2,858 tools by hand would be a full-time job. Running BlackArch unmodified in Docker gives you the real binaries with your home directory shared.BlackArch es Arch Linux (paquetes pacman); Linux-C.O.S es de la familia Debian (apt). Los formatos no son compatibles, y reempaquetar 2.858 herramientas a mano sería un trabajo a tiempo completo. Ejecutar BlackArch sin modificar en Docker te da los binarios reales compartiendo tu carpeta personal.

When can I just download the ISO?¿Cuándo podré simplemente descargar la ISO?

When boot testing is done, releases will be published on GitHub Releases with SHA-256 checksums. Until then, build it yourself with Docker — the steps work on Linux, macOS and Windows.Cuando terminen las pruebas de arranque, las versiones se publicarán en GitHub Releases con sus sumas SHA-256. Hasta entonces, compílala tú con Docker — los pasos funcionan en Linux, macOS y Windows.

How do I start my computer from the USB stick?¿Cómo arranco el ordenador desde la memoria USB?

Disable Secure Boot in the firmware setup, then press the boot-menu key while the computer starts (often F12, F9, F8 or Esc) and pick the USB stick. Step-by-step guide.Desactiva Secure Boot en la configuración del firmware y pulsa la tecla del menú de arranque mientras se enciende el ordenador (suele ser F12, F9, F8 o Esc); elige la memoria USB. Guía paso a paso.

Can I install it next to Windows?¿Puedo instalarla junto a Windows?

Yes, but be careful: the installer's default “Erase disk” deletes Windows. Back up first, then choose “Install alongside” or manual partitioning. You need 60 GB of free space. Trying the live session first changes nothing on your disk.Sí, pero con cuidado: la opción por defecto del instalador, “Borrar disco”, elimina Windows. Haz una copia de seguridad y elige “Instalar junto a” o el particionado manual. Necesitas 60 GB libres. Probar la sesión live primero no cambia nada en tu disco.

Why is the ISO so big?¿Por qué la ISO es tan grande?

It installs kali-linux-everything plus the blue-team layer: about 14.6 GiB. Baking the BlackArch image in makes it much larger — that's optional, see the build steps.Instala kali-linux-everything más la capa blue-team: unos 14,6 GiB. Incluir la imagen de BlackArch la hace mucho más grande — es opcional, mira los pasos de compilación.

Does it work with Secure Boot?¿Funciona con Secure Boot?

Not yet. Disable Secure Boot in your firmware to boot it. Signed boot is on the roadmap.Todavía no. Desactiva Secure Boot en tu firmware para arrancarla. El arranque firmado está en la hoja de ruta.

What is the live session password?¿Cuál es la contraseña de la sesión live?

User kali, password kali — the same convention as Kali's live images. The installed system uses the user and password you create in the installer.Usuario kali, contraseña kali — la misma convención que las imágenes live de Kali. El sistema instalado usa el usuario y la contraseña que crees en el instalador.

What are the MISP / TheHive / Wazuh passwords?¿Cuáles son las contraseñas de MISP / TheHive / Wazuh?

MISP's are generated randomly the first time you run cos-stacks up misp; see them with cos-stacks creds misp. TheHive and Wazuh use their upstream first-login defaults, which you must change on first login (cos-stacks creds reminds you).Las de MISP se generan al azar la primera vez que ejecutas cos-stacks up misp; míralas con cos-stacks creds misp. TheHive y Wazuh usan sus valores iniciales de fábrica, que debes cambiar en el primer inicio de sesión (cos-stacks creds te lo recuerda).

Is the firewall on? Is the disk encrypted?¿El firewall está activo? ¿El disco está cifrado?

The ufw firewall blocks incoming connections from the first boot, before the network starts. Disk encryption (LUKS2) is offered by the installer — tick “Encrypt system”. AppArmor and auditd are on too. Details: hardening.El firewall ufw bloquea las conexiones entrantes desde el primer arranque, antes de que arranque la red. El cifrado del disco (LUKS2) lo ofrece el instalador — marca “Cifrar el sistema”. AppArmor y auditd también están activos. Detalles: hardening.

Is there an ARM / Apple Silicon version?¿Hay versión para ARM / Apple Silicon?

No — the ISO is amd64 only, because many tools still lack arm64 builds. You can build it on an Apple Silicon Mac and run it under emulation in UTM, which is slow.No — la ISO es solo amd64, porque muchas herramientas aún no tienen versión arm64. Puedes compilarla en un Mac con Apple Silicon y ejecutarla emulada en UTM, aunque es lento.

How do I update it?¿Cómo se actualiza?

Like Kali: sudo apt update && sudo apt full-upgrade. Automatic updates are prepared but opt-in, because upgrading a rolling toolset unattended can break it mid-engagement.Como Kali: sudo apt update && sudo apt full-upgrade. Las actualizaciones automáticas están preparadas pero son opcionales, porque actualizar un conjunto rolling sin supervisión puede romperlo en medio de un trabajo.

Does the OS or this website collect any data?¿El sistema o este sitio recopilan datos?

No telemetry is added by Linux-C.O.S. This website loads nothing from third parties, sets no cookies, and only remembers your language and theme choice in your own browser.Linux-C.O.S no añade telemetría. Este sitio no carga nada de terceros, no usa cookies y solo recuerda tu idioma y tema en tu propio navegador.

Is it legal to use these tools?¿Es legal usar estas herramientas?

Using security tools against systems you don't own or have written permission to test is illegal in most countries. Use Linux-C.O.S for authorized testing, research, learning and defense.Usar herramientas de seguridad contra sistemas que no son tuyos o sin permiso escrito para probarlos es ilegal en la mayoría de los países. Usa Linux-C.O.S para pruebas autorizadas, investigación, aprendizaje y defensa.

How can I help?¿Cómo puedo ayudar?

Boot-test the ISO and report what happens, review the hardening, or send a pull request. Everything lives in the GitHub repository.Prueba a arrancar la ISO y cuenta qué pasa, revisa el hardening o envía un pull request. Todo está en el repositorio de GitHub.
