Build the ISOCompilar la ISO

  1. Get the sourceDescarga el código

    git clone https://github.com/BlackSentinel-tech/Linux-C.O.S.git
cd Linux-C.O.S/build

  2. Decide on BlackArch (optional)Decide sobre BlackArch (opcional)

    By default the BlackArch image is downloaded on the first boot of an installed system. To bake it into the ISO instead (much bigger ISO, zero download after boot):Por defecto la imagen de BlackArch se descarga en el primer arranque del sistema instalado. Para incluirla en la ISO (ISO mucho más grande, cero descargas después):

    docker build -t linux-cos/blackarch:latest blackarch-container/
docker save linux-cos/blackarch:latest -o config/includes.chroot/opt/linux-cos/blackarch-image.tar

  3. Build (in the background)Compila (en segundo plano)

    nohup ./build.sh > build.out 2>&1 &
tail -F build.out output/build.log

    nohup keeps the build running if you close the terminal; tail -F follows the logs (the second one appears once the ISO build itself starts). The ISO lands in build/output/live-image-amd64.hybrid.iso.nohup mantiene la compilación aunque cierres la terminal; tail -F sigue los logs (el segundo aparece cuando empieza la compilación de la ISO). La ISO queda en build/output/live-image-amd64.hybrid.iso.

Boot itArráncala

USB stickMemoria USB

Writing the ISO erases everything on the stick.Grabar la ISO borra todo lo que haya en la memoria.

  • Windows / macOS / Linux: balenaEtcher — pick the ISO, pick the stick, Flash.Windows / macOS / Linux: balenaEtcher — elige la ISO, elige la memoria, Flash.
  • Windows: Rufus — when it asks, choose “Write in DD Image mode” (an exact copy; the other mode breaks this kind of ISO).Windows: Rufus — cuando pregunte, elige “Escribir en modo Imagen DD” (una copia exacta; el otro modo estropea este tipo de ISO).
  • Linux: dd — check the device name with lsblk first, it overwrites whatever you point it at.Linux: dd — comprueba antes el nombre del dispositivo con lsblk, sobrescribe lo que le indiques.
# replace /dev/sdX with your stick (see lsblk)# cambia /dev/sdX por tu memoria (mira lsblk)
sudo dd if=live-image-amd64.hybrid.iso of=/dev/sdX bs=4M status=progress conv=fsync

Starting a laptop from the USB stickArrancar un portátil desde la memoria USB

  1. Turn off Secure BootDesactiva Secure Boot

    Restart and open the firmware setup (usually F2, Del or Esc while the maker's logo shows; on Windows: Settings → Recovery → Advanced startup → UEFI Firmware Settings). Find Secure Boot (often under Boot or Security) and set it to Disabled, then save and exit.Reinicia y entra en la configuración del firmware (normalmente F2, Supr o Esc mientras aparece el logo del fabricante; desde Windows: Configuración → Recuperación → Inicio avanzado → Configuración de firmware UEFI). Busca Secure Boot (suele estar en Boot o Security), ponlo en Disabled, guarda y sal.

  2. Open the boot menuAbre el menú de arranque

    With the stick plugged in, restart and press the boot-menu key: commonly F12 (Dell, Lenovo), F9 (HP), Esc or F8 (ASUS), F12 (Acer). Pick the USB stick — choose the “UEFI” entry if there are two.Con la memoria puesta, reinicia y pulsa la tecla del menú de arranque: suele ser F12 (Dell, Lenovo), F9 (HP), Esc o F8 (ASUS), F12 (Acer). Elige la memoria USB — si hay dos entradas, la que dice “UEFI”.

  3. Try it live firstPruébala primero en modo live

    The live session changes nothing on your disk. Your Windows (or other system) is untouched until you run the installer and choose a disk option.La sesión live no cambia nada en tu disco. Tu Windows (u otro sistema) queda intacto hasta que ejecutes el instalador y elijas una opción de disco.

Keeping Windows? Read this before installing¿Quieres conservar Windows? Lee esto antes de instalar

The installer's default, Erase disk, deletes everything on that disk — Windows included. Back up first, then choose Install alongside (dual boot) or manual partitioning.La opción por defecto del instalador, Borrar disco, elimina todo lo que hay en ese disco — Windows incluido. Haz una copia de seguridad y elige Instalar junto a (arranque dual) o el particionado manual. Install guideGuía de instalación
