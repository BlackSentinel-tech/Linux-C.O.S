    About this listSobre esta lista

    Built from Kali's and Parrot's tool metapackages and BlackArch's package groups; a tool is listed under every category its distribution gives it. Parrot-only tools are listed only when the build really installs them. BlackArch: an ISO built with the full image has all of them preinstalled; with the default image (downloaded on first boot) install what you need inside the container with pacman -S <name>.Generada a partir de los metapaquetes de herramientas de Kali y Parrot y los grupos de paquetes de BlackArch; cada herramienta aparece en todas las categorías que le da su distribución. Las exclusivas de Parrot solo aparecen si la compilación las instala de verdad. BlackArch: una ISO compilada con la imagen completa las trae todas preinstaladas; con la imagen por defecto (descargada en el primer arranque) instala las que necesites dentro del contenedor con pacman -S <nombre>.
