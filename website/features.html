Kali

kali-linux-everything plus each of the 28 kali-tools-* categories listed explicitly, so a failing category is visible in the build log instead of hidden inside one metapackage.kali-linux-everything más cada una de las 28 categorías kali-tools-* listadas explícitamente, para que una categoría que falle se vea en el log en lugar de quedar escondida dentro de un metapaquete.

Parrot

The tools Parrot ships that no Kali category covers (computed by diffing both catalogs). Parrot's repo is pinned at priority 1 — a pure fallback that can never replace a Kali library.Las herramientas de Parrot que ninguna categoría de Kali cubre (calculadas comparando ambos catálogos). El repositorio de Parrot está fijado con prioridad 1 — un respaldo que nunca puede reemplazar una biblioteca de Kali.

BlackArch

Arch packages can't be installed with apt, so BlackArch runs as itself in Docker: blackarch-shell opens it with your home directory mounted at the same path. One-off commands work too: blackarch-shell nmap -h.Los paquetes de Arch no se instalan con apt, así que BlackArch corre tal cual en Docker: blackarch-shell lo abre con tu carpeta personal montada en la misma ruta. También sirve para un comando suelto: blackarch-shell nmap -h.

Heavy platforms, on demandPlataformas pesadas, bajo demanda

A SIEM baked into an image means every install shares the same admin password. cos-stacks starts them only when you need them. MISP gets random passwords on its first start; TheHive and Wazuh begin with their upstream first-login defaults, which cos-stacks creds shows so you can change them.Un SIEM horneado en una imagen significa que todas las instalaciones comparten la misma contraseña de admin. cos-stacks los arranca solo cuando los necesitas. MISP recibe contraseñas aleatorias en su primer inicio; TheHive y Wazuh empiezan con los valores de fábrica de sus proyectos, que cos-stacks creds muestra para que los cambies.
