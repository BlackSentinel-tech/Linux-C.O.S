    About this listSobre esta lista

    Built from Kali's and Parrot's tool metapackages and BlackArch's package groups. A Parrot badge means Parrot lists the tool; a handful of Parrot-only names don't resolve on a Kali base and are skipped by the build (see the build notes). Inside the container, install any BlackArch tool with pacman -S <name>.Generada a partir de los metapaquetes de herramientas de Kali y Parrot y los grupos de paquetes de BlackArch. La etiqueta Parrot significa que Parrot lista la herramienta; algunos nombres exclusivos de Parrot no se resuelven sobre una base Kali y la compilación los omite (ver notas de compilación). Dentro del contenedor, instala cualquier herramienta de BlackArch con pacman -S <nombre>.
